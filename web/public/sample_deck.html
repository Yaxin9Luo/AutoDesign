The Problem in One Sentence

Imagine you ask your Agent to book a flight. It invokes five different tools, but the second one returns an incorrect price. The result? It books a non-existent flight and confidently tells you, "Booking confirmed."

This is exactly the failure mode we're studying — silent compounding of upstream tool errors, masked by an agent's own confidence.

The Three Shifts

AI is evolving from single-turn assistants into multi-agent systems (Claude Code, Devin). These systems operate on the assumption of absolute tool reliability, yet in real-world scenarios, tools are prone to errors, timeouts, and inconsistent returns. An early-stage anomaly can trigger a cascading failure, propagating through shared memory to contaminate the entire workflow.

From Assistants to Agents
