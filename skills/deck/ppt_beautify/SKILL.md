# PPT Beautify

Use for a supplied PPT/PPTX that needs redesign without losing its source meaning.

## Stage: enhance

Preserve slide order, core claims, charts, screenshots, assets, and wording unless the request explicitly permits change. Require an editable redesign rather than whole-slide rasterization.

## Stage: plan

Ingest first, map every source slide to editable frames, and plan what stays versus changes before markup. Read `beautify_policy`.

## Stage: critique

Check source-slide coverage, lost evidence, copy drift, brand assets, accidental whole-slide rasterization, and mismatches between source intent and redesigned hierarchy.

## Stage: repair

Repair frames, groups, and source metadata while retaining source-slide identity. Read `beautify_policy`.
