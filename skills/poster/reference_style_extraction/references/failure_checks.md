# Failure checks

Reject a blueprint when styling precedes the macro map; a top-level region is unassigned, duplicated, hidden in chrome, oversized, overlapping, or includes gutters; a detached bottom block was absorbed; a raster edge became a frame; or empty QR/logo space survives.

Also reject invented table/formula rules, an unrendered or stale comparison, and any reference content or asset in the analysis or output. Repair from the preceding blueprint without regressing an already-correct body-region map.
