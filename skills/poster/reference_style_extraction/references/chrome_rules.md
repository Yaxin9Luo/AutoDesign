# Chrome rules

Keep body geometry independent from decoration. Put routes, rails, curves, connectors, and edge accents in one root `chrome-layer` behind content; chrome never owns body regions or crosses text, figures, tables, or formulas. Header-confined motifs belong in `identity-header`.

Collapse reference QR or logo reservations and reflow remaining geometry. Do not replace them. Transfer an outer frame only when it is an inset, repeated, visibly designed treatment, not a screenshot edge. Extract table and formula treatment only when visibly observed; do not fall back to the normal AutoDesign skin.
