# Poster Visual Recipe

Use for editable campaign, event, social, product, and paper posters. Visual references transfer style only.

## Stage: enhance

Classify scenario, density, hierarchy, evidence needs, and whether reference mode is active before expanding the brief. Keep paper evidence distinct from campaign imagery.

## Stage: plan

Choose one archetype and author browser-native layout. For paper posters, read `paper_layout`, `source_flow`, and `typography_aesthetics`; read `reference_mode` only for reference runs.

## Stage: critique

Check source coverage, readable density, identity-only header, panel flow, typography hierarchy, restrained surfaces, and visual coherence. In reference mode, judge the reference-owned geometry and style rather than the default poster treatment.

## Stage: repair

Repair structure and source flow before cosmetic polish; preserve editable HTML and provenance. Read the affected resource, including `reference_mode` for reference runs.
