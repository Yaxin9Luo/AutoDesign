# Reference mode

Reference posters provide style and geometry only. Start from the sanitized reference blueprint and active canvas, retain non-visual hard gates, and do not leak the default academic three-column skeleton, palette, typography, or header chrome into the reference treatment.

Never copy reference text, claims, logos, QR codes, figures, tables, links, or assets. Use target-paper content and source evidence only. During repair, preserve the reference-derived body-region map while fixing local findings.
