# Typography and aesthetics

Use browser-native layout and editable text. Paper headers expose only title, authors, and institutions as plain text: no venue, project, code, contact, logo, icon, QR, badge, or subtitle row. Wrap long titles inside the title row.

Choose exactly one curated palette, apply its exact CSS variables and `data-palette-id`, and use a white or near-white header with one top accent rule. Keep panels, tables, and source wrappers neutral; use compact heading bands and restrained accents. Do not invent logo lookup, brand colors, random section colors, gradients, default indigo/purple treatment, heavy outlines, or decorative color containers.

Use offline KaTeX-compatible TeX only in wide formula blocks or native table rows; never inject scripts or place equations in narrow chips, cards, or KPI cells. Preserve readable hierarchy and avoid repeated boxed-card layouts.
