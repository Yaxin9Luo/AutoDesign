# Table jobs

Choose one job before markup: `benchmark`, `ablation`, `taxonomy`, `recipe`, `complexity`, `method-setup`, or `limitations-evidence`. Use the original `ingest_table_*` crop when it is paper evidence, especially a headline result. A native table may summarize or interpret it but must not replace or fully reconstruct it.

Use prose only when there is no stable row/column relationship. Poster-native tables usually have three to seven rows and three to six columns; split or summarize wider content. State units, metric direction, protocol scope, baselines, and a one-to-three-bullet nearby takeaway.
