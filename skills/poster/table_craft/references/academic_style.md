# Academic table style

Native summaries use restrained booktabs-like rules: top, header/mid, optional light row separators, and bottom. Avoid boxed full-cell grids, heavy outer frames, double rules, and ordinary vertical rules. Keep source crops faithful; this style does not restyle source evidence.

Use white or lightly tinted headers with dark text. Poster-native summary/readout tables default to all-left alignment: left-align every `th` and `td`, including numeric values. Do not right-align or decimal-align numeric columns. Use all-center alignment only for short pure symbol/numeric matrices with no prose cells or row labels, and apply it with an explicit cell-level selector. Use one emphasis mechanism per table and reserve zebra striping for genuinely long or wide tables.
