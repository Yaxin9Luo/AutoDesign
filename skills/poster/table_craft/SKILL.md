# Poster Table Craft

Use for paper-poster source tables and native academic summaries. Source crops remain evidence; native tables interpret them.

## Stage: enhance

Identify whether the source needs a source crop, native summary, or prose readout. A native table may interpret source evidence but must not impersonate or replace it.

## Stage: plan

Choose one table job and reserve readable space before markup. Read `table_jobs` and `academic_style`.

## Stage: critique

Flag replaced or duplicated source evidence, unreadable tables, missing benchmark context, excessive rules/fills, and style drift. Preserve the source crop when it is the evidence contract.

## Stage: repair

Improve table information design before CSS; preserve source truth and use restrained native-table rules. Read `repair`.
