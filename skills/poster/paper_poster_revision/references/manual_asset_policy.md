# Manual asset policy

Use the paper, attachments, and explicit user references as source of truth. Verify paper figure/table number and caption before placement; do not trust ingest order or visual plausibility. Re-crop PDF evidence if axes, legends, or bottoms are clipped or surrounding text is included.

Use an identity asset only when the user explicitly requests it in the current revision. Prefer an exact file that is already staged or directly supplied. If none is available, search only the organization's or conference's official website or official media kit, download the exact mark as a local portable asset, and record its relative path and exact official source URL in `code_editor_done.json` under `fetched_identity_assets`.

Never perform unsolicited logo lookup. Never generate, redraw, approximate, or substitute a different organization or event mark, and never create a text badge as a logo replacement. Preserve the recognizability of an allowed supplied or officially retrieved file. Do not hotlink the remote source in the final HTML.
