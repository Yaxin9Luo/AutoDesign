# Export QA

Use this pack for editable final artifacts. Deterministic feedback remains authoritative.

## Stage: plan

Plan native text, tables, named layers, and source-grounded images. Set artifact export guarantees and record font, imagery, and tradeoffs. Read `export_checks` for artifact-specific checks.

## Stage: critique

Treat blockers, P0 lint, layout, provenance, sanitizer, and export findings as one repair queue. Grade the render and editable contract together; reject broken bounds, missing assets, rasterized text, or unverifiable evidence.

## Stage: repair

Fix blockers before polish. Repair slots/groups before children, use local editable operations, and preserve source evidence. Read `export_checks` before finalizing.
