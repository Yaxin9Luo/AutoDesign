# PDF Visual Curation

Use only with PDF source attachments. It selects source evidence; ingest remains the source of figures and tables.

## Stage: enhance

Preserve the explicit image policy and distinguish method, evidence, table, and qualitative source visuals from decorative imagery. Keep page/caption provenance.

## Stage: plan

After ingest, select source visuals before generated mood imagery and reserve editable source slots. Read `visual_role_policy`.

## Stage: critique

Flag missing high-value evidence, weak role coverage, low-confidence captions without nearby support, or source blocks missing source id, page, and caption provenance.

## Stage: repair

Swap or crop source blocks, update their slots and metadata together, and keep generated imagery secondary. Read `visual_role_policy`.
