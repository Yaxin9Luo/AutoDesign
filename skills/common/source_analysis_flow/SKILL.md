# Source Analysis Flow

Use for content-bearing documents or multi-image source packs, not a single logo or style reference.

## Stage: enhance

Preserve source policy, audience, goal, and requested scope. Distinguish `source_only`, `smart_match`, and `no_images`; separate source evidence from generated mood imagery.

## Stage: plan

Ingest first, then make outline, per-frame content, and asset-slot plans before authored detail. Use `html_artifact` as primary and preserve source ids. Read `image_policy`.

## Stage: critique

Check staged-plan coverage, evidence provenance, visual capacity, editability, and compliance with the selected image-policy mode.

## Stage: repair

Repair frames, slots, groups, and source metadata before child styling; preserve ids unless structure changes. Read `image_policy`.
