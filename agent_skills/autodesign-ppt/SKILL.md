# AutoDesign PPT

Create a coherent research talk from user-provided sources while preserving
editable content and explicit source grounding.

## Portability boundary

- Work only from the sources the user provides and the resources bundled with
  this Skill.
- Put run state and generated files in a user-selected output directory.
- Never write generated artifacts or run state inside this Skill directory.
- Keep the installed Skill usable without a separate application or service.
